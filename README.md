# Time Series Forecasting Portfolio

[![gdp-analysis](https://github.com/yding-lab/Time-series_forecasting/actions/workflows/gdp.yml/badge.svg)](https://github.com/yding-lab/Time-series_forecasting/actions/workflows/gdp.yml)

Statistical modeling and forecasting in R. The lead project is a reproducible comparison of quarterly GDP growth for the **United States and Canada (averaged) and Germany**. The data is downloaded from the OECD, models are evaluated chronologically against simple baselines, and forecasts come with prediction intervals. The report and its figures are generated by the code in CI. Five earlier analyses (markets, trade, inflation, VAR, GARCH) are kept as supporting work.

## Lead project: quarterly GDP growth, US/Canada average vs Germany

**Report: [report/comparative_gdp_report.md](report/comparative_gdp_report.md)**, generated by `gdp/build_report.R`. It supersedes the original course report, which is kept unchanged in [archive/](archive/README.md) (see *Original report* below).

| | |
|---|---|
| **Series** | **US/Canada average**: the unweighted mean of the US and Canadian growth rates, quarter by quarter. It's not an official North American aggregate (US GDP is more than ten times Canada's). **Germany**: Germany alone, which the original report used as a stand-in for Europe. Results describe Germany, not Europe |
| **Target and units** | Quarter-over-quarter growth of seasonally adjusted real GDP, `100 × [log(GDP_t) − log(GDP_t−1)]`, **percent per quarter, not annualized**. Forecast errors are in percentage points |
| **Data** | OECD Quarterly National Accounts: real GDP, chain-linked volume, national currency, calendar and seasonally adjusted, for USA, CAN and DEU. Levels from 1995-Q1 to 2023-Q4 give 115 growth observations (1995-Q2 to 2023-Q4). Retrieved 2026-10-30 |
| **Methods** | STL, Holt-Winters, ADF, `auto.arima`, Ljung-Box, ARCH-LM, GARCH(1,1), Welch t-test / F-test |
| **Validation** | **Rolling origin**: 55 expanding-window origins, horizons 1–8, ARIMA vs naive, seasonal-naive and historical-mean baselines, with interval coverage. Plus a single 8-quarter holdout (2022-Q1 to 2023-Q4) |

### Key results (from the generated report)

![Quarterly real GDP growth, US/Canada average and Germany, 1995-Q2 to 2023-Q4](report/figures/growth_series.png)

**Growth.** Mean growth was 0.591% per quarter for the US/Canada average and 0.312% for Germany. The 0.279 pp difference isn't significant (Welch 95% CI −0.083 to 0.641, p = 0.13), and Germany's series is slightly *more* variable (variance ratio 0.84). The 2008–09 and 2020 quarters dominate the extremes.

![Rolling-origin RMSE by horizon for ARIMA, mean, naive and seasonal naive](report/figures/error_by_horizon.png)

**Forecasting.** Over 412 rolling-origin forecasts per model, the **historical mean has the lowest RMSE for both series** (1.872 and 1.879 pp). ARIMA's RMSE is 2.807 for the US/Canada average and 1.956 for Germany. One quarter ahead for the US/Canada average, ARIMA is worse than even the naive forecast (RMSE ratio 1.129). Quarterly growth has little predictable short-run dynamics beyond its average, so the simple baseline wins and the report keeps that result.

![Actual growth and ARIMA holdout forecasts with 80% and 95% prediction intervals, 2022-Q1 to 2023-Q4](report/figures/holdout_forecast.png)

**Intervals.** Nominal 80% intervals covered 86–92% of outcomes (too wide) and nominal 95% intervals 89–94% (too narrow). That's the signature of normal intervals meeting fat-tailed errors. The calm 2022–23 holdout sits well inside its intervals.

**Backtest caveat.** All evaluation uses today's *revised* GDP data. A real-time forecaster would have seen earlier, unrevised vintages, so these are pseudo-out-of-sample errors and probably understate real-time errors. A vintage-based evaluation (OECD original-release archive, or ALFRED for the US) isn't done here.

### Reproduce from a fresh clone

Requires R 4.5 (CI uses 4.5.3) and internet access to `sdmx.oecd.org`.

```bash
Rscript install_packages.R               # pinned: CRAN snapshot 2026-10-01 (forecast 9.0.2, rugarch 1.5-6, tseries 0.10-63)
Rscript gdp/fetch_oecd_gdp.R             # -> data/comparative_gdp_oecd.csv + .SOURCE.txt (query, retrieval time)
Rscript gdp/comparative_gdp_analysis.R   # -> results/*.csv, results/gdp_results.md, results/figures/
Rscript gdp/rolling_origin_evaluation.R  # -> results/rolling_origin.md, results/rolling_origin_metrics.csv
Rscript gdp/build_report.R               # -> report/comparative_gdp_report.md, report/figures/
```

Run from the repository root. The scripts never install packages themselves: a missing package stops the run with the install command. CI (`.github/workflows/gdp.yml`) runs exactly these commands on every push. It also warns if the committed report no longer matches a fresh run (for example, after an OECD revision). A manual run with `commit_report` regenerates the report and commits it.

**Data and license.** The data isn't committed. `fetch_oecd_gdp.R` downloads it from the OECD SDMX API (`DSD_NAMAIN1@DF_QNA` v1.1, key `Q.Y.USA+CAN+DEU.S1.S1.B1GQ._Z._Z._Z.XDC.L.N.T0102`) and records the query and retrieval time next to it. Reuse is governed by the [OECD terms and conditions](https://www.oecd.org/en/about/terms-conditions.html). The OECD revises national accounts, so a later download can change the numbers slightly.

### Original report

The original PDF ([archive/](archive/README.md)) labels the series "North America" and "Europe". Its headline numbers aren't reproduced when its own method is applied to its stated source: it gives mean growth of 4.48% vs 0.76% per quarter, a persistent gap of about 3.9 pp and ARIMA(1,0,1), where this analysis gives 0.591% vs 0.312%, no significant gap and MA(1). A mean of 4.48% per quarter (about 19% a year) can't come from QoQ growth of US and Canadian real GDP. The original input file wasn't kept, so the cause can't be confirmed; a differently defined input series is the most likely explanation. The full comparison table is in the report. The PDF's methods carry over; its quantitative conclusions shouldn't be cited.

### Limitations

- The US/Canada average is unweighted, and Germany isn't Europe. A GDP-weighted North American series and a euro-area aggregate would answer the original regional question more directly.
- 2008–09 and 2020 are structural breaks. The GARCH(1,1) estimates sit at the boundary of the parameter space, so a few pandemic quarters drive the fit.
- Normal prediction intervals don't fit the fat-tailed errors. Bootstrap or Student-t intervals are worth comparing.
- Revised data, not real-time vintages (above).
- The 2024–25 forecasts in the report can now be checked against actuals by extending `END` in the fetch script.

## Supporting analyses

These are earlier coursework analyses. Their data came from course materials, isn't included, and isn't redistributable here, so **these scripts haven't been re-run, and their findings are as originally reported.** Each script stops with a clear message if its file is missing (checked in CI).

| Script | Topic | Methods | Required file |
|---|---|---|---|
| `supporting/01_financial_market_forecasting.R` | Gold, oil and yen prices (monthly, 2005–) | Decomposition, ACF/CCF, Holt-Winters, MAPE on a 6-month holdout | `data/goy.xls` |
| `supporting/02_ratio_forecasting.R` | China export/import ratio | AR, trend + seasonal regression, GLS with AR errors. As reported: AR beat GLS out of sample, MAPE ~6.47% vs ~7.34% | `data/trade.xls` |
| `supporting/03_inflation_forecasting.R` | U.S. CPI and monthly inflation | Trend + seasonal regression, ARMA residuals, SARIMA | `data/Inflation.xls` |
| `supporting/04_interest_rate_gdp_var_analysis.R` | U.S. GDP growth and Fed funds rate | ADF, VAR, lag selection, impulse responses | `data/ffrategdp.xls` |
| `supporting/05_garch_volatility_modeling.R` | U.S. inflation volatility | SARIMA mean, ARCH-LM, GARCH(1,1) | `data/Inflation.xls` |

Run any of them with `Rscript supporting/<script>.R` from the repository root, after placing the file in `data/`.

## Layout

```
gdp/
  fetch_oecd_gdp.R                 download + validate the OECD input, record provenance
  comparative_gdp_analysis.R       the lead analysis (holdout, baselines, intervals, diagnostics, GARCH)
  rolling_origin_evaluation.R      expanding-window cross-validation vs baselines, horizons 1-8
  build_report.R                   the report and its figures, from the outputs above
report/                            generated report + figures (committed; refreshed by CI)
archive/                           the original PDF report, superseded, kept unchanged
supporting/                        01-05 earlier analyses (data not included)
R/packages.R                       package check shared by all scripts (no silent installs)
install_packages.R                 pinned package installation
.github/workflows/gdp.yml          fresh-clone reproduction in CI
```
